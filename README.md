# پارس کم (Pars Cam)

سامانه **کاملاً ایرانی و بومی** نظارت تصویری — رابط کاربری فارسی، تقویم جلالی، طراحی RTL.

## اجرای رابط کاربری (Next.js)

```bash
cd web
npm install
npm run dev
```

سپس به آدرس [http://localhost:3000](http://localhost:3000) بروید.

ورود آزمایشی: کاربر `admin` با هر رمزی.

## صفحات

- `/login` — ورود
- `/dashboard` — داشبورد فرماندهی
- `/monitor` — نظارت و ضبط زنده
- `/alarms` — هشدارها
- `/recordings` — آرشیو ضبط
- `/scanner` — اسکنر RTSP شبکه داخلی
- `/settings` — تنظیمات و درباره محصول

## بک‌اند فعلی

منطق استریم/ضبط RTSP همچنان در `../parscam.py` (Flask) قرار دارد. این پوشه `web` لایه رابط کاربری مدرن Next.js است.
